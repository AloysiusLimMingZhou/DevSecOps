# DevSecOps Project
This project is a demo of a DevSecOps lifecycle on a small backend server with 5 API calls using REST API practices. 

## Phase 1: Basic Backend Development with Test
1. Backend API Development with NestJS (Routes, Services, Exeption Filters, Middlewares, DTOs, Pipes)
2. Database Connection with TypeORM & Data Migration with TypeORM CLI
3. Software Testing (Unit Spec Test, Integration Test, E2E Test)

## Phase 2: Containerization, Basic DevSecOps Lifecycle (Current)
1. Docker & Containerization
2. CI Test with Github Actions
3. Dependency Scanning with Dependabot
4. Code Scanning with CodeQL
5. Git Branches Intermediate -> Advance (Commit Audit & Rollback, basic intro to GitOps)
